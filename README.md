# 🔐 Password Generator

Gerador de senhas aleatórias com controle de tamanho, tipos de caracteres e análise de força. Feito com HTML, CSS e JavaScript puro.

---

## ✨ Funcionalidades

- **Geração de senhas aleatórias** com tamanho configurável (8 a 64 caracteres)
- **Escolha de tipos de caractere**:
  - Letras maiúsculas (A-Z)
  - Letras minúsculas (a-z)
  - Números (0-9)
  - Símbolos (!@#$%...)
- **Análise de força** em tempo real:
  - Fraca (1 barra vermelha)
  - Média (2 barras amarelas)
  - Forte (3 barras verdes)
- **Cópia rápida** para a área de transferência
- **Histórico** das últimas senhas geradas
- **Design responsivo** (mobile, tablet, desktop)
- **Dark mode** com paleta customizável via CSS variables

---

## 🛠️ Tecnologias

- **HTML5** — estrutura semântica
- **CSS3** — variáveis, Grid, Flexbox, responsividade
- **JavaScript (ES Modules)** — lógica do app, manipulação do DOM
- **Material Symbols** — ícones do Google

Sem frameworks, sem bibliotecas. Apenas o básico do front-end.
